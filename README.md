# Job Copilot

Track your job applications, let AI parse job postings, match them against your CV, and see what the market is actually asking for.

> 🚧 Work in progress — see [ROADMAP.md](ROADMAP.md).

## Tech stack

- **Framework:** Next.js (App Router), React, TypeScript
- **Styling:** Tailwind CSS
- **Database:** PostgreSQL + Drizzle ORM *(planned)*
- **AI:** Claude API with structured output *(planned)*
- **Testing:** Vitest, Playwright *(planned)*
- **CI/CD:** GitHub Actions, Vercel *(planned)*

## Getting started

```bash
npm install
npm run dev
```

Open http://localhost:3000.
